# ပါဠိတက္ကသိုလ်ညောင်တုန်း ကျောင်းသားဟောင်းများ လိပ်စာစုဆောင်းရေးနှင့် စာအုပ်ထုတ်ဝေရေး Webapp - ကနဦး မှတ်စုနှင့် အကြံပြုချက်များ

## ၁။ ထပ်မံထည့်သွင်းသင့်သော အချက်အလက်များ (Data Fields)

| အမျိုးအစား | ထပ်ဖြည့်သင့်သော အချက်အလက် | ဘာကြောင့် လိုအပ်သလဲ |
| --- | --- | --- |
| **ပုဂ္ဂိုလ်ရေး/ဘွဲ့** | **ရဟန်း/လူ ခွဲခြားမှု နှင့် ဂုဏ်ထူးဘွဲ့များ** (ဥပမာ- ဓမ္မာစရိယ၊ M.A.၊ Ph.D.) | စာအုပ်ထုတ်သည့်အခါ ဘွဲ့တော်နှင့်တွဲ၍ ဂုဏ်ပြုဖော်ပြနိုင်ရန်။ |
| **ကျောင်းတိုက်မှတ်တမ်း** | **ပညာသင်ကြားခဲ့သော ခုနှစ်** (ဥပမာ- ၁၃၆၀ မှ ၁၃၆၅ ထိ) | ခေတ်ပြိုင်သူငယ်ချင်းများကို ပြန်လည်ရှာဖွေရာတွင် အလွန်အသုံးဝင်ပါသည်။ |
| **လက်ရှိအခြေအနေ** | **လက်ရှိတာဝန်** (ကျောင်းထိုင်၊ စာချ၊ လူဝတ်လဲပြီးပါက အလုပ်အကိုင်) | အချင်းချင်း ဆက်သွယ်ရာတွင် ပိုမိုအဆင်ပြေစေရန်။ |
| **ဆက်သွယ်ရန်** | **Viber / Telegram / Email** | ပြည်ပရောက်နေသူများအတွက် ဖုန်းနံပါတ်ထက် Viber/Telegram က ပိုအသုံးဝင်ပါသည်။ |
| **တည်နေရာ (ပြည်ပ)** | **နိုင်ငံ (Country) နှင့် မြို့ (City)** | ပြည်ပရွေးချယ်ပါက တိုင်း/မြို့နယ်အစား နိုင်ငံနှင့် မြို့ကို ပြောင်းလဲဖြည့်စွက်စေရန်။ |
| **ခွင့်ပြုချက်** | **Privacy Consent Checkbox** | "လိပ်စာစာအုပ်တွင် ဖော်ပြရန် သဘောတူသည်" နှင့် "Webapp ပေါ်တွင် ဖုန်းနံပါတ်ပြသခွင့် ပြု/မပြု" ရွေးချယ်စေရန်။ |

## ၂။ မသမာသူများရန်မှ ကာကွယ်ခြင်းနှင့် ကိုယ့်အချက်အလက် ပြန်စစ်နိုင်ခြင်း

* **တစ်ဝက်တစ်ပျက် ဖုံးကွယ်ပြသခြင်း (Data Masking):**
  Webapp တွင် အမည်/ဘွဲ့တော်ဖြင့် ရှာဖွေကြည့်ရှုသည့်အခါ အချက်အလက်အပြည့်အစုံကို မပြဘဲ ဖုန်းနံပါတ်ကို `09-79***890`၊ လိပ်စာကို မြို့နယ်အဆင့်လောက်သာ ပြသထားရန် (ကာယကံရှင်က မိမိနာမည် ပါ/မပါ နှင့် မှန်/မမှန် သိနိုင်ပြီး သူစိမ်းက ဖုန်းနံပါတ်နှင့် လိပ်စာအတိအကျကို ခိုးယူ၍မရစေရန်)။
* **စာရင်းအရှည်ကြီး မပြဘဲ ရှာဖွေမှသာ ပြသခြင်း (Search-Only View):**
  လူအားလုံး၏ စာရင်းကို စာမျက်နှာအလိုက် (Pagination) အကုန်ကြည့်ခွင့်မပေးဘဲ Bot Scraping မှ ကာကွယ်ရန် အမည် သို့မဟုတ် ကျောင်းဆောင်ကို တိတိကျကျ ရိုက်ရှာမှသာ ရလဒ်ပြသည့်ပုံစံ လုပ်ဆောင်ရန်။
* **ပြင်ဆင်ခွင့်ကို Admin စိစစ်ချက်ဖြင့်သာ ခွင့်ပြုခြင်း (Edit Request Queue):**
  တိုက်ရိုက်ပြင်ဆင်ခွင့်မပေးဘဲ **"ပြင်ဆင်ရန် တောင်းဆိုမည် (Request Correction)"** ခလုတ်ထားကာ Admin Panel တွင် စစ်ဆေးအတည်ပြု (Approve) ပြီးမှသာ Database ထဲ ပြောင်းလဲစေရန်။
* **ဝင်ရောက်ခွင့် စကားဝှက် (Community Access Code) နှင့် Bot ကာကွယ်ရေး:**
  ကျောင်းသားဟောင်း Viber/Telegram Group များတွင်သာ ဖြန့်ဝေထားသော ဂဏန်း ၄ လုံး သို့မဟုတ် ၆ လုံးပါ **Access Code** (သို့မဟုတ် ကျောင်းတိုက်နှင့်ပတ်သက်သော မေးခွန်းတစ်ခု) ထည့်သွင်းပြီးမှ Form ဖြည့်ခွင့်/ရှာဖွေခွင့် ပေးခြင်းနှင့် **Cloudflare Turnstile (CAPTCHA)** ထည့်သွင်းခြင်း။

## ၃။ Print Book (လိပ်စာစာအုပ်) ထုတ်ဝေရန်အတွက် ကြိုတင်ပြင်ဆင်မှု

1. **Dropdown များဖြင့်သာ ရွေးချယ်စေခြင်း:** ပြည်တွင်းအတွက် တိုင်းဒေသကြီးနှင့် မြို့နယ်များကို Dropdown (MIMU စာရင်းအတိုင်း) ရွေးချယ်စေပြီး စာအုပ်ထုတ်သည့်အခါ တိုင်း/မြို့နယ်အလိုက် အလိုအလျောက် စီပေးနိုင်ရန်။
2. **Zawgyi မှ Unicode အလိုအလျောက်ပြောင်းခြင်း:** Backend တွင် Unicode သို့ အလိုအလျောက် ပြောင်းလဲသိမ်းဆည်းပေးသည့်စနစ် (Auto-normalization) ထည့်သွင်းရန်။
3. **One-Click Export:** Admin Panel မှနေ၍ ပြည်တွင်း/ပြည်ပ ခွဲခြားပြီး တိုင်းဒေသကြီးအလိုက် စီပြီးသား **Excel (.xlsx)** ဖိုင်နှင့် စာအုပ်ပုံစံ **Print-ready PDF** ဖိုင်များကို တစ်ချက်နှိပ်ရုံဖြင့် ထုတ်ယူနိုင်ရန်။

## ၄။ အခြား Alumni Network များ လုပ်ဆောင်လေ့ရှိသော ပုံစံများ ("Search First, Then Submit")

* **အဆင့် ၁ (အရင်ရှာ):** အသုံးပြုသူ ဝင်လာလျှင် Form အသစ်တန်းမဖြည့်ခိုင်းဘဲ မိမိဘွဲ့တော်/အမည်ကို အရင်ရှာခိုင်းရန်။
* **အဆင့် ၂ (စစ်ဆေး/ပြင်ဆင်):** ရှာတွေ့ပြီး အချက်အလက်မှားနေပါက "ပြင်ဆင်ရန်တင်ပြမည်" ကို နှိပ်စေပြီး၊ ရှာမတွေ့မှသာ "အချက်အလက်အသစ် ထည့်သွင်းမည်" Form ကို ပွင့်စေရန် (Duplicate ကို ၈၀% ခန့် လျှော့ချနိုင်ရန်)။
* **အဆင့် ၃ (Two-Tier Access):** Public အတွက် ဖုန်းနံပါတ်ဖျောက်ထားပြီး Admin က အတည်ပြုပေးထားသော Verified Members Login ဝင်မှသာ ဖုန်းနံပါတ်နှင့် လိပ်စာအပြည့်အစုံကို မြင်ရသည့်စနစ် အသုံးပြုရန်။
