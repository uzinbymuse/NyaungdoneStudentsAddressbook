# ယုံကြည်မှု၊ Consent-First မူဝါဒနှင့် Print Book လုံခြုံရေး မှတ်စုများ

## အဓိက မူ — သဘောတူမှ ထည့်ပါ (Consent-First & Trust)
Directory ဆိုသည်မှာ လူများ သဘောတူပြီး ပါဝင်သော စာရင်းသာ ဖြစ်ရမည်။ ကျောင်းတွင် ရှိပြီးသား စာရင်းကို သဘောမတူဘဲ တိုက်ရိုက်တင်ခြင်း မပြုရ။

### အခြေခံ စည်းမျဉ်း ၃ ချက်
1. **အများပြည်သူ မြင်နိုင်သော စာရင်း မလုပ်ရ:** အတည်ပြုပြီးသား ကျောင်းသားဟောင်းများသာ ဝင်ကြည့်နိုင်သည့် စနစ် ("ကျောင်းသားဟောင်းများသာ ဝင်တဲ့ အခန်း" — Members-only Room) ဖြစ်ရမည်။
2. **တစ်ကွက်ချင်းစီ Visibility ရွေးချယ်ခွင့်:** အမည်နှင့် ဘွဲ့ရနှစ်ကို ပြမည်၊ ဖုန်းကို မပြဘူး စသည်ဖြင့် အချက်အလက်တစ်ခုချင်းစီအတွက် ကိုယ်တိုင် ရွေးချယ်နိုင်ရမည်။ Directory မှ လုံးဝ opt-out လုပ်ခွင့်လည်း ရှိရမည်။
3. **Web နှင့် Print Consent သီးခြားစီ:** Web တွင် ပြသရန် သဘောတူတိုင်း Print စာအုပ်တွင် ပါဝင်မည်ဟု မဆိုလိုပါ။

## Data Fields နှင့် မတောင်းသင့်သော အချက်အလက်များ
* **မဖြစ်မနေ ပါသင့်သည်များ:** ဘွဲ့ရနှစ်/အတန်း (Batch)၊ လက်ရှိနေထိုင်သည့် နိုင်ငံ (ပြည်တွင်း/ပြည်ပ ခွဲရန်)၊ လက်ရှိ ကျောင်းတိုက်/အလုပ်/တာဝန်၊ ဆက်သွယ်ရန် နည်းလမ်း (ဖုန်းအပြင် Viber / Telegram ID)
* **Optional ထည့်သင့်သည်များ:** ဓာတ်ပုံ (တစ်ပုံတည်း၊ ကိုယ်တိုင်တင်မှ)၊ အီးမေးလ်၊ ယခင်အမည် / သံဃာအမည် + လူအမည်၊ အထူးမှတ်ချက် (Public) နှင့် ကျောင်းသားဟောင်းအသင်းအတွက် အကြံပေးချက် (Admin Only)
* **Admin Only:** ဖောင်တင်သူ၏ ဆက်သွယ်လာရာလမ်းကြောင်း/အတည်ပြုချက် မှတ်တမ်း၊ "Print မှာ မထည့်ပါနဲ့" တောင်းဆိုချက်
* **လုံးဝ မတောင်းသင့်သည်များ:** မှတ်ပုံတင်အမှတ် (NRC)၊ မွေးနေ့ အတိအကျ၊ ဘဏ်အကောင့်၊ အိမ်အမှတ် အတိအကျ (ရွာ/ရပ်ကွက်အဆင့်သာ တောင်းရန်)

## ကိုယ့်အချက်အလက် စစ်ဆေးခြင်း၊ Claim လုပ်ခြင်းနှင့် ပြင်ဆင်ခြင်း (အဆင့် ၃ ဆင့်)
1. **ကိုယ့်စာရင်း ရှာကြည့်ခြင်း:** Login ဝင်ပြီးမှသာ အမည်နှင့် ဘွဲ့ရနှစ်ဖြင့် ရှာခွင့်ပြုရန် (Login မဝင်ဘဲ အပြင်လူက စမ်းရှာခွင့် မပေးရ)။
2. **ကိုယ့်စာရင်း တောင်းဆိုခြင်း (Claim):** "ဒါက ကျွန်တော့် စာရင်းပါ" နှိပ်ပါက Admin ထံ တောင်းဆိုချက် ရောက်ရှိပြီး ဖုန်းနံပါတ်၊ ဘွဲ့ရနှစ်၊ ကျောင်းဆောင် စသည့် အချက် ၂-၃ ခုဖြင့် တိုက်စစ်အတည်ပြုရန်။
3. **ပြင်ဆင်ချက် တောင်းဆိုခြင်း:** တိုက်ရိုက်ပြင်ခွင့်အစား "ပြင်ဆင်ချက် တောင်းဆို → Admin အတည်ပြု" + Audit Log ထားရန်။
* **Annual Re-verification:** တစ်နှစ်တစ်ကြိမ် မိမိအချက်အလက် မှန်ကန်သေးကြောင်း ပြန်လည်အတည်ပြုခိုင်းသည့် စနစ်ထားရန်။

## မသမာသူများ အချက်အလက်ရယူမှု ကာကွယ်ရေး (Anti-Scraping & Trust)
* Google တွင် ရှာမတွေ့စေရန် `noindex` ထားပြီး Directory ကို Login ဝင်မှသာ ဖွင့်ရန်။
* Bulk download / copy ကာကွယ်ပြီး Export ခလုတ်ကို Admin သာ အသုံးပြုနိုင်ရန်။
* Search Rate Limiting + ရလဒ်ကို တစ်ကြိမ်လျှင် ၂၀ ဦးသာ ပြသခြင်း + ဖုန်းနံပါတ်ကို Mask လုပ်ထားပြီး "ပြမလား" နှိပ်မှ (သို့မဟုတ် ခွင့်ပြုမှ) ပြသခြင်း။
* Admin မှ အကောင့်အသစ်များကို စိစစ်အတည်ပြုခြင်း။
* **"Report" ခလုတ်:** သံသယဖြစ်ဖွယ် ဆက်သွယ်မှု/ငွေတောင်းခံမှုများ တွေ့ရှိပါက Admin ထံ ချက်ချင်း တိုင်ကြားနိုင်ရန်။
* **Print Vendor NDA:** ပုံနှိပ်တိုက်သို့ Data ပေးပါက ဤစာအုပ်အတွက်သာ သုံးရန်၊ ပြီးလျှင် ဖျက်ပေးရန်နှင့် ပြင်ပသို့ မပေးရန် စာချုပ်ပါဝင်ရမည်။

## ပြည်တွင်း / ပြည်ပ ခွဲခြားခြင်းနှင့် Print Book စည်းမျဉ်းများ
* နိုင်ငံသားအလိုက် မဟုတ်ဘဲ **လက်ရှိ နေထိုင်သည့် နိုင်ငံ** အလိုက် ပြည်တွင်း/ပြည်ပ ခွဲခြားရန်။
* Print အတွက် သီးခြား Consent ယူရန် (Print တွင် ဖုန်းနံပါတ် မဖြစ်မနေ မထည့်ဘဲ အမည်၊ ဘွဲ့ရနှစ်၊ မြို့/နိုင်ငံသာ ထည့်ရန် သို့မဟုတ် ဖုန်းထည့်လိုသူသာ သီးခြားရွေးခွင့်ပေးရန်)။
* **Freeze & Proofread:** စာအုပ်မရိုက်မီ ပြင်ဆင်နိုင်သည့် နောက်ဆုံးရက် (Freeze Date) ကြေညာပြီး တစ်ဦးချင်းစီ၏ စာမျက်နှာကို PDF ဖြင့် ပြန်ပို့ကာ မှန်/မမှန် အတည်ပြုချက် ယူရန်။
* **စာအုပ်အစီအစဉ်:** ဘွဲ့ရနှစ် → ပြည်တွင်း/ပြည်ပ → တိုင်းဒေသကြီး/နိုင်ငံ အစီအစဉ်ဖြင့် စီရန်။
