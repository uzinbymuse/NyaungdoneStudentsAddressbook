# ပါဠိတက္ကသိုလ် ညောင်တုန်း ကျောင်းသားဟောင်းများ လိပ်စာစာရင်း
**ဖောင်နမူနာ + သဘောတူစာသား + Admin SOP (ကူးယူ၍ တိုက်ရိုက် အသုံးပြုနိုင်သော မူ)**

> **ဤစာရွက်ကို ဘယ်သူ ဖတ်ရမလဲ:** အပိုင်း ၁၊ ၂၊ ၃ နှင့် ၄ (အတည်ပြုလွှာ) ကို ဖောင်တင်သူ ကျောင်းသားဟောင်းများထံ ပေးရန် ဖြစ်သည်။ အပိုင်း ၄ (ပုံနှိပ်တိုက် သဘောတူညီချက်) နှင့် အပိုင်း ၅ ကို Admin ကိုယ်တိုင် သိမ်းထားရန် ဖြစ်သည်။ စာရွက်တစ်ခုလုံးကို အများပြည်သူထံ မဖြန့်ပါနှင့်။

## ဒီအစီအစဉ်အတွက် သတ်မှတ်ထားသော အခြေအနေ
| အချက် | သတ်မှတ်ချက် |
| --- | --- |
| **ပါဝင်မည့် အရေအတွက်** | ကျောင်းသားဟောင်း ၁,၀၀၀ ဦး အောက် |
| **Admin** | Admin ၁ ဦး တည်းက အတည်ပြု၊ ပြင်ဆင်၊ ထုတ်ယူ (export) လုပ်မည် |
| **ဖြန့်ဝေမည့်သူ** | ကျောင်းသားဟောင်းများအတွက်သာ — အများပြည်သူ မဟုတ်ပါ |
| **အဓိက ရည်ရွယ်ချက် (၁)** | Print စာအုပ်တွင် မည်သူမျှ မကျန်ရစ်စေရန် |

### ပုံစံ (က) နှင့် ပုံစံ (ခ)
* **ပုံစံ (က) — အခုပဲ စသုံးနိုင်သော ပုံစံ (အကြံပြု):** Google Form သို့မဟုတ် စာရွက်ဖောင်ဖြင့် စစုပြီး Admin က တစ်ဦးချင်း စစ်ဆေးသည်။ Print စာအုပ်အတွက် အချက်အလက် ပြည့်စုံသွားပြီးမှ ပုံစံ (ခ) Webapp သို့ လွှဲပြောင်းနိုင်သည် (အစက ပြန်စုရန် မလို)။
* **ပုံစံ (ခ) — နောင်တွင် Webapp ဖြင့် လုပ်မည့် ပုံစံ:** ကိုယ်ပိုင် အကောင့်ဖြင့် ဝင်ပြီး ကိုယ့်စာရင်းကို ကိုယ်တိုင် ပြင်နိုင်သော စနစ်။
* **မည်သူမှ မကျန်စေရန် အကြံပြုချက်:** ဖောင်ကို တစ်ခါတည်း အကုန်လုံးဆီ ပို့တာထက် **အတန်း/နှစ် (Batch) အလိုက် ကိုယ်စားလှယ်တစ်ယောက်စီကို အရင်ပေးပြီး** သူ့အတန်းက လူစာရင်းနှင့် တိုက်ခိုင်းတာ ပိုစုံမည်။

**နိုင်ငံ ရွေးချယ်ရန် စာရင်း (နမူနာ):** မြန်မာ၊ ထိုင်း၊ စင်ကာပူ၊ မလေးရှား၊ သီရိလင်္ကာ၊ အိန္ဒိယ၊ ဂျပန်၊ ကိုရီးယား၊ အမေရိကန်၊ ဗြိတိန်၊ ဩစတြေးလျ၊ အခြား (ရေးရန်)။

## ၂။ သဘောတူစာသား အပြည့်အစုံ (ကူးယူ၍ သုံးရန်)

### ဖောင်တွင် ပြမည့် မိတ်ဆက် စာသား
ပါဠိတက္ကသိုလ် ညောင်တုန်း ကျောင်းသားဟောင်းများ အချင်းချင်း အလွယ်တကူ ဆက်သွယ်နိုင်ရန်နှင့် မည်သူမျှ မကျန်ရစ်သော Print လိပ်စာစာအုပ် ပြုလုပ်နိုင်ရန်အတွက် ဤဖောင်ဖြင့် အချက်အလက်များ စုဆောင်းခြင်း ဖြစ်သည်။
သင် ဖြည့်လိုက်သော အချက်အလက်များကို မည်သူ မြင်ရမည်၊ မည်သည့်နေရာတွင် သုံးမည် ဆိုသည်ကို အောက်တွင် ရှင်းလင်းစွာ ရေးထားသည်။ သေချာစွာ ဖတ်ပြီးမှ သဘောတူပါက ဖောင်ကို ဆက်ဖြည့်ပါ။ သဘောမတူသော အချက်ရှိလျှင် သက်ဆိုင်ရာ Checkbox ကို အမှန်မခြစ်ဘဲ ထားနိုင်သည်။

### သဘောတူညီချက် အချက် ၇ ချက်
1. ဤစာရင်းကို အများပြည်သူ မည်သူမျှ မမြင်ရပါ။ Admin က အတည်ပြုပြီးသော ကျောင်းသားဟောင်းများသာ Login ဝင်ပြီး ကြည့်နိုင်မည်။ Google ကဲ့သို့သော ရှာဖွေရေး စနစ်များတွင် ပေါ်မည် မဟုတ်ပါ။
2. သင် ပြရန် ရွေးထားသော အချက်များကိုသာ ပြမည်။ မပြရန် ရွေးထားသော အချက်များကို Admin ၁ ဦးတည်းကသာ အတည်ပြုရန်နှင့် ဆက်သွယ်ရန်အတွက် မြင်ရမည်။
3. သင်၏ အချက်အလက်များကို ကျောင်းသားဟောင်းများ ဆက်သွယ်ရေး ရည်ရွယ်ချက်မှလွဲ၍ အခြား မည်သည့် ရည်ရွယ်ချက်အတွက်မျှ အသုံးမပြုပါ။ ကြော်ငြာ၊ စီးပွားရေး၊ သို့မဟုတ် ပြင်ပ အဖွဲ့အစည်းများထံ ရောင်းချခြင်း၊ ပေးပို့ခြင်း လုံးဝ မလုပ်ပါ။
4. Print စာအုပ်ကို ကျောင်းသားဟောင်းများအတွက်သာ ထုတ်ဝေမည် ဖြစ်ပြီး အများပြည်သူထံ ရောင်းချမည် မဟုတ်ပါ။
5. သင်၏ အချက်အလက် မှားနေခြင်း၊ ပြောင်းလဲသွားခြင်း ရှိလျှင် Admin ထံ အချိန်မရွေး ဆက်သွယ်၍ ပြင်ဆင်နိုင်သည်။
6. သင်၏ အချက်အလက်ကို စာရင်းမှ လုံးဝ ဖယ်ရှားလိုလျှင် Admin ထံ ဆက်သွယ် တောင်းဆိုနိုင်သည်။ Web မှ ဖယ်ရှားခြင်းကို တောင်းဆိုချက်ရပြီး ၁၄ ရက်အတွင်း ဆောင်ရွက်ပေးမည်။ Print စာအုပ် ရိုက်နှိပ်ပြီးပါက ထုတ်ဝေပြီးသော စာအုပ်များမှ ဖယ်ရှား၍ မရနိုင်ကြောင်း နားလည်ပါသည်။
7. အချက်အလက်များကို လုံခြုံစွာ သိမ်းဆည်းရန် အတတ်နိုင်ဆုံး ကြိုးစားမည် ဖြစ်သော်လည်း အင်တာနက်ပေါ်တွင် မည်သည့်စနစ်မျှ ၁၀၀ ရာခိုင်နှုန်း လုံခြုံသည်ဟု အာမ မခံနိုင်ပါ။ ထို့ကြောင့် မပြလိုသော အချက်ကို အစကတည်းက မဖြည့်ခြင်းသည် အလုံခြုံဆုံး ဖြစ်သည်။

### Checkbox များ
* `☐ [မဖြစ်မနေ]` အထက်ပါ အချက်များကို ဖတ်ပြီး နားလည်ပါသည်။ ကျွန်ုပ် ဖြည့်သော အချက်အလက်များသည် မှန်ကန်ပါသည်။
* `☐ [မဖြစ်မနေ]` ကျွန်ုပ်၏ အမည်၊ ဘွဲ့၊ ဘွဲ့ရနှစ်၊ ကျောင်းဆောင်၊ လက်ရှိ မြို့နှင့် နိုင်ငံ၊ လက်ရှိ ကျောင်းတိုက် / အလုပ် / တာဝန်တို့ကို အတည်ပြုပြီးသော ကျောင်းသားဟောင်းများသာ ကြည့်နိုင်သော Web စာရင်းတွင် ပြရန် သဘောတူပါသည်။
* `☐ [ရွေးချယ်ခွင့်]` ကျွန်ုပ်၏ အချက်အလက်များကို Print လိပ်စာစာအုပ်တွင် ထည့်သွင်း ထုတ်ဝေရန် သဘောတူပါသည်။ (ဤ Checkbox ကို အမှန်မခြစ်လျှင် Web တွင်သာ ပါမည်ဖြစ်ပြီး Print စာအုပ်တွင် ပါမည် မဟုတ်ပါ။)
* `☐ [ရွေးချယ်ခွင့်]` ကျွန်ုပ်၏ ဖုန်း နံပါတ်ကို Print လိပ်စာစာအုပ်တွင် ထည့်သွင်းရန် သဘောတူပါသည်။ (အမှန်မခြစ်လျှင် Print တွင် ဖုန်း ပါမည် မဟုတ်ပါ။ Web တွင် ပြခြင်း / မပြခြင်းနှင့် သပ်သပ် ဖြစ်သည်။)

## ၃။ အကွက် ဖြည့်နည်း လမ်းညွှန် (ဖောင်တင်သူများအတွက်)
* **အမည်:** သူငယ်ချင်းများ မှတ်မိသော အမည် (ဘွဲ့အမည် + ယခုအခေါ်အမည် မတူလျှင် နှစ်မျိုးလုံး ဥပမာ- အရှင်ဥတ္တမ (ယခု — ဦးဥတ္တမ))။
* **ဘွဲ့ရနှစ် / Batch:** မမှတ်မိလျှင် အနီးစပ်ဆုံး ခုနှစ် + “ခန့်မှန်း”။
* **ကျောင်းဆောင်:** အကြာဆုံး နေခဲ့သော ကျောင်းဆောင် (နှစ်ခုနေခဲ့လျှင် နှစ်ခုလုံး)။
* **လက်ရှိ နေထိုင်သော နိုင်ငံ:** နိုင်ငံသားဖြစ်မှုမဟုတ်ဘဲ ယခုနေထိုင်သည့် နိုင်ငံ (ပြည်တွင်း/ပြည်ပ ခွဲရန်)။
* **တိုင်း/မြို့/ရွာ-ရပ်ကွက်:** ရွာ/ရပ်ကွက်အဆင့်သာ (အိမ်အမှတ်/လမ်းအမှတ် မရေးရ)။
* **ဖုန်းနံပါတ်:** ပြည်ပဆို Country code (+66...) ထည့်ရေးရန်။
* **ဓာတ်ပုံ:** တင်လိုမှသာ မျက်နှာရှင်းလင်းသော ပုံတစ်ပုံ။
* **Admin ထံ အကြံပေးချက်:** Admin ၁ ဦးတည်းသာ မြင်ရမည်။
* **သတိပြုရန်:** မှတ်ပုံတင်အမှတ်၊ မွေးနေ့အတိအကျ၊ ဘဏ်အကောင့်၊ အိမ်လိပ်စာအတိအကျ လုံးဝ မတောင်းပါ။

## ၄။ Print စာအုပ် အတွက် အတည်ပြုလွှာနှင့် ပုံနှိပ်တိုက် သဘောတူညီချက်

### ၄.၁ တစ်ဦးချင်း အတည်ပြုလွှာ (Proof) — Print မရိုက်မီ ပို့ရန်
> “မင်္ဂလာပါ။ ပါဠိတက္ကသိုလ် ညောင်တုန်း ကျောင်းသားဟောင်း လိပ်စာစာအုပ်တွင် ပါဝင်မည့် သင်၏ အချက်အလက်များကို အောက်တွင် ပြထားပါသည်။ Print စာအုပ်တွင် ဤအတိုင်း ရိုက်နှိပ်မည် ဖြစ်ပါသည်။
> အမည် — ……………… ဘွဲ့ — ……………… ဘွဲ့ရနှစ် — ………………
> လက်ရှိ နေရာ — ……………… (မြို့၊ တိုင်းဒေသကြီး / နိုင်ငံ) လက်ရှိ ကျောင်းတိုက် / တာဝန် — ………………
> ဖုန်း — ……………… (သင် သဘောတူထားမှသာ ပါမည်)
> မှားနေသော အချက်၊ ပြောင်းလိုသော အချက် ရှိလျှင် [ရက်စွဲ ထည့်ရန်] နောက်ဆုံးထား၍ ပြန်လည် အကြောင်းကြားပေးပါ။ ထိုရက်ကျော်လွန်ပါက အချက်အလက်များကို ပိတ်သိမ်း (freeze) မည် ဖြစ်ပြီး Print တွင် ပြင်၍ ရတော့မည် မဟုတ်ပါ။ အကြောင်းပြန်ချက် မရရှိပါက ဤအတိုင်း မှန်ကန်သည်ဟု မှတ်ယူပြီး ရိုက်နှိပ်ပါမည်။
> Print စာအုပ်တွင် မပါလိုတော့ပါက ထိုရက် မတိုင်မီ အကြောင်းကြားပါ — Web စာရင်းတွင်သာ ဆက်လက် ပါဝင်နိုင်ပါသည်။”

*(မှတ်တမ်းတင်ရန်: အမည်၊ အတည်ပြုရက်စွဲ၊ နည်းလမ်း၊ ပြင်ဆင်ချက် — Print ပြီးနောက် အနည်းဆုံး ၁ နှစ် သိမ်းထားရန်)*

### ၄.၂ ပုံနှိပ်တိုက်နှင့် ဒေတာ လက်ခံသူ သဘောတူညီချက် (နမူနာ)
1. လက်ခံရရှိသော အချက်အလက်များကို ဤ လိပ်စာစာအုပ် ပုံနှိပ်ခြင်း အတွက်သာ အသုံးပြုမည်။
2. မည်သည့် ပြင်ပလူ/အဖွဲ့အစည်းထံသို့မျှ ပေးပို့၊ ရောင်းချ၊ ကူးယူခွင့်ပြုခြင်း မလုပ်ပါ။
3. ပုံနှိပ် ပြီးဆုံးပြီး `[၇]` ရက်အတွင်း ဖိုင်များ/မိတ္တူများ အားလုံးကို ဖျက်ဆီးပြီး Admin ထံ စာဖြင့် အကြောင်းကြားမည်။
4. ဖိုင် ပျောက်ဆုံး/ပေါက်ကြားပါက သိရှိပြီး ၂၄ နာရီအတွင်း Admin ထံ ချက်ချင်း အကြောင်းကြားမည်။
5. ချိုးဖောက်ပါက ဖြစ်ပေါ်လာသော ထိခိုက်မှုများအတွက် တာဝန်ယူမည်။
*(လက်မှတ် မထိုးပါက ဖုန်းနံပါတ်ပါသော ဖိုင်ကို မပေးဘဲ အမည်/ဘွဲ့ရနှစ်/မြို့/နိုင်ငံသာ ပေးရန်)*

## ၅။ Admin ၁ ဦးတည်းအတွက် လုပ်ငန်းစဉ် ၅ ဆင့်နှင့် စစ်ဆေးရန် စာရင်း
1. **လက်ခံ မှတ်တမ်းတင်ခြင်း:** ဖောင်အမှတ်စဉ် သတ်မှတ်ရန် (ဥပမာ- `ND-0001`)။
2. **အတည်ပြုခြင်း:** အမည် + ဘွဲ့ရနှစ် + ကျောင်းဆောင် + ဖုန်း ဖြင့် တိုက်စစ်ရန်။
3. **အမည်တူများ ပေါင်းစည်းခြင်း:** အမည် + ဘွဲ့ရနှစ် + ဖုန်းဖြင့် ရှာပြီး အသစ်ဆုံးကို ယူကာ အဟောင်းကို "ပေါင်းစည်းပြီး" ဟု မှတ်ထားရန် (ချက်ချင်း မဖျက်ရ)။
4. **ပြသခြင်း:** တင်သူရွေးချယ်မှုအတိုင်းသာ ပြရန်၊ Login + Verified Only၊ Export ကို Admin သာ လုပ်ရန်။
5. **Print အတွက် ပိတ်သိမ်းခြင်း:** Freeze Date ကြေညာ → Proof ပို့ → `PRINT-FINAL` ဖိုင် သီးခြားကူးသိမ်း → နောက်ပိုင်း ပြင်ဆင်ချက်များကို Web အတွက်သာ ပြင်ရန်။
